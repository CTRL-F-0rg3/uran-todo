# Uran To-Do

Minimalistyczna lista zadań w ciemnym motywie Urana (Compose Multiplatform for Desktop).

## Funkcje
- Dodawanie, zaznaczanie i usuwanie zadań
- Filtry: Wszystko / Aktywne / Zrobione
- Auto-zapis do `~/.local/share/uran/todo/data.json`
- Import z plików `.txt` i `.json`
- Eksport do `.json`
- Niestandardowy pasek tytułu w stylu macOS

## Uruchomienie

    ./gradlew run
